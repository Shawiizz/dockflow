# Dockflow

Deploy Docker Compose apps to your own servers.

```sh
npm install -g @dockflow-tools/cli
dockflow --help
```

The package runs the dockflow binary of your platform, installed as an optional dependency (`@dockflow-tools/cli-<os>-<arch>`): nothing is downloaded by a script at install time. Installing with `--omit=optional` leaves the binary out.

Documentation: https://dockflow.shawiizz.dev
