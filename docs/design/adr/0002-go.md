# ADR-0002: Go as the implementation language

- Status: Accepted
- Date: 2026-10-25

## Context

Dockflow 1.x is TypeScript on Bun. The rewrite has to load Compose files with the exact semantics of the Compose specification, talk to the Docker Engine API, speak SSH, ship a static binary to servers ([ADR-0004](0004-ephemeral-agent.md)) and stay small enough for one maintainer.

## Decision

Dockflow v2 is written in Go (the current stable release), built as static binaries for linux/amd64, linux/arm64, darwin/amd64, darwin/arm64 and windows/amd64.

Libraries chosen up front:

| Need | Library |
|---|---|
| Compose loading (interpolation, overrides, profiles, `extends`) | `github.com/compose-spec/compose-go/v2`, the loader Docker Compose itself uses |
| Docker Engine API | the official Moby Go client |
| SSH, `known_hosts`, `ssh-agent` | `golang.org/x/crypto/ssh` and its `knownhosts` and `agent` packages |
| Registry push and pull | `github.com/google/go-containerregistry` |
| Secrets | `github.com/getsops/sops/v3` (decrypt) and `filippo.io/age` |
| Templates (Jinja) | `github.com/nikolalohinski/gonja/v2` ([ADR-0006](0006-compose-as-written.md)) |
| CLI | `github.com/spf13/cobra` |
| Local web UI server | the standard library (`net/http`, `embed`); the frontend stack is chosen in M5 ([ADR-0016](0016-interfaces.md)) |
| MCP server | the official MCP Go SDK |
| Embedded CA roots for the agent | `golang.org/x/crypto/x509roots/fallback` |

Any other dependency needs a line in the pull request saying why the standard library is not enough.

## Consequences

- The Compose specification is not reimplemented: the module that loads Compose in Dockflow is the one Docker uses.
- The agent binary is small and has no runtime, which keeps the upload to a server cheap.
- The author has to work in a language other than TypeScript. Go's small surface keeps the cost bounded.
- The Angular WebUI, the Nextra docs site and the TypeScript MCP server of 1.x have no counterpart to reuse; the web UI's server and the MCP server are rewritten in Go.

## Alternatives considered

- **TypeScript on Bun.** Faster to start for the author. Rejected because Compose loading would have to be reimplemented, the Docker client is weaker and compiled binaries weigh 60 to 100 MB.
- **Rust.** Small, safe binaries. Rejected for slower development and no official Compose loader.
